# Homebrew tap

Apps by Alejandro Buján.

Tendedero is now in Homebrew itself, so this tap is no longer needed:

```sh
brew install tendedero
```

Installed it from this tap before? Move to the official cask with:

```sh
brew uninstall --cask alejandrobujan/tap/tendedero
brew install tendedero
brew untap alejandrobujan/tap
```

Your screenshots and settings stay where they are.

| Cask | App |
|---|---|
| `tendedero` | [Tendedero](https://github.com/alejandrobujan/tendedero): your screenshots, hung out to dry |
